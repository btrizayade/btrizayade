## 📝 Featured Projects

### 📚 [BookMind](https://github.com/btrizayade/BookMind) · [Live Demo](https://book-mind-ashy.vercel.app/)

An AI-powered book discovery platform that helps readers find books matching their interests, preferences, and mood.

- Integrates Google Books and Open Library for book discovery and metadata.
- Uses Google Gemini for literary summaries and analysis.
- Includes a personalized recommendation engine based on book characteristics and reader preferences.
- Features user authentication and persistent data storage.

**Tech:** React, TypeScript, Python, FastAPI, SQLAlchemy, PostgreSQL, Google Gemini.

### 💡 [Echo](https://github.com/btrizayade/Echo)

A creative memory system for capturing, organizing, connecting, and rediscovering fragments of a person's own ideas.

- Supports text captures and image/audio attachments.
- Organizes fragments through themes and favorites.
- Includes a deterministic resurfacing mechanism to bring older captures back to the user's attention.
- Built around a human-centered principle: the system organizes and resurfaces creative material without generating it on the user's behalf.

**Tech:** Python, FastAPI, SQLAlchemy, SQLite, React, TypeScript, Vite, Pytest.

### 🧩 [Vox](https://github.com/btrizayade/Vox)

An Augmentative and Alternative Communication (AAC) project focused on accessible communication through customizable pictograms and visual resources.

Currently under development.

### 🚚 [Ponto a Ponto](https://github.com/btrizayade/Ponto-A-Ponto)

A delivery-planning project exploring priority queues, order management, and delivery-route organization.

The project applies data structures and object-oriented programming to a practical logistics scenario, with a Python backend and a React interface.

**Tech:** Python, React, SQLite.
